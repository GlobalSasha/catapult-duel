# Catapult Duel

Готовая локальная версия пошаговой дуэли катапульт для двух игроков на одном
устройстве.

Текущий порядок разработки и статус этапов:
[Implementation Roadmap](./docs/Implementation-Roadmap.md).

## Быстрый запуск

Нужен Node.js 22.12 или новее.

```bash
npm install
npm run dev
```

Откройте [http://localhost:5173/](http://localhost:5173/).

## Как играть

1. Выберите один из двух больших миров.
2. По очереди расставьте базы обоих игроков: выберите позицию катапульты и до
   трёх защитных объектов в пяти слотах. Между игроками появляется закрытый
   экран передачи устройства.
3. Камера покажет только базу активного игрока; база соперника находится далеко
   за рельефом и препятствиями.
4. Выберите камень, огонь, лёд, алмаз или бомбу. Камень бесконечный, запас
   специальных снарядов указан на кнопках.
   Огонь поджигает на два хода, лёд снимает горение и ограничивает силу,
   алмаз наносит высокий точный урон, а бомба поражает область и может задеть
   стрелявшего.
5. Посмотрите на погоду и ветер в верхней части экрана. Ветер меняется перед
   каждым ходом; жара усиливает огонь, дождь сокращает горение, снег замедляет
   полёт и продлевает лёд, песчаная буря сокращает подсказку траектории.
6. Используйте дерево, сетку и металлический лист возле базы как защиту.
   Повторные попадания оставляют трещины, снижают прочность и в итоге превращают
   защиту или препятствие арены в обломки.
7. Активный игрок настраивает угол и силу выстрела.
8. Нажмите «Огонь» или пробел: камера проследит за снарядом через динамический
   большой мир.
9. Передавайте устройство друг другу после каждого выстрела.
10. Побеждает игрок, первым обнуливший здоровье соперника.

На экране победы можно сразу начать реванш или вернуться к выбору арены.

## Управление

- мышь или касание — выбор арены, ползунки и кнопки;
- `←` / `→` — выбор арены;
- `Enter` или `Space` — начать матч;
- `Space` — выстрел или реванш;
- `1`–`5` — выбрать тип снаряда;
- `Esc` — вернуться к выбору арены после матча.

На телефоне используется горизонтальная ориентация. В портретном режиме игра
покажет подсказку повернуть устройство.
