# Catapult Duel

Готовая локальная версия пошаговой дуэли катапульт для двух игроков на одном
устройстве.

Текущий порядок разработки и статус этапов:
[Implementation Roadmap](./docs/Implementation-Roadmap.md).

## Быстрый запуск

Нужен Node.js 22.12 или новее.

```bash
npm install
npm run dev
```

Откройте [http://localhost:5173/](http://localhost:5173/).

## Как играть

1. После заставки выберите режим, противника и одну из 12 арен на карте
   кампании. Короткий экран подготовки знакомит с полем перед расстановкой.
2. По очереди расставьте базы обоих игроков: выберите позицию катапульты и
   постройте вокруг неё открытый сверху каменный замок. Между игроками
   появляется закрытый экран передачи устройства.
3. Камера покажет только базу активного игрока; база соперника находится далеко
   за рельефом и препятствиями.
4. Выберите камень, огонь, лёд, алмаз или бомбу. Камень бесконечный, запас
   специальных снарядов указан на кнопках.
   Огонь поджигает на два хода, лёд снимает горение и ограничивает силу,
   алмаз наносит высокий точный урон, а бомба поражает область и может задеть
   стрелявшего.
5. Посмотрите на погоду и ветер в верхней части экрана. Ветер меняется перед
   каждым ходом; жара усиливает огонь, дождь сокращает горение, снег замедляет
   полёт и продлевает лёд, песчаная буря сокращает подсказку траектории.
6. Катапульта стоит на верхней площадке высокой каменной башни. Обычные
   выстрелы разбивают башню за четыре точных попадания; повреждения оставляют
   трещины, а разрушенный замок превращается в обломки и больше не блокирует
   снаряды. Точно рассчитанный выстрел может попасть по катапульте сверху, не
   разрушая башню.
7. От каждой башни к противнику идёт отряд рыцарей с 75 единицами здоровья.
   После полного раунда — когда выстрелили оба игрока — оба живых отряда делают
   один шаг. На десятом шаге отряд достигает вражеской башни и побеждает.
   По рыцарям можно стрелять любыми снарядами; бомба также поражает их взрывом.
8. Активный игрок настраивает угол и силу выстрела.
9. Нажмите «Огонь» или пробел: камера проследит за снарядом через динамический
   большой мир.
10. Передавайте устройство друг другу после каждого выстрела.
11. Побеждает игрок, первым уничтоживший катапульту соперника или проведший
    живых рыцарей за десять раундов. Если оба отряда доходят одновременно,
    объявляется ничья.

На экране победы можно сразу начать реванш или вернуться к выбору арены.

## Управление

- мышь или касание — выбор арены, ползунки и кнопки;
- `←` / `→` — выбор арены;
- `Enter` или `Space` — пропустить заставку, подтвердить выбор или начать матч;
- `Space` — выстрел или реванш;
- `1`–`5` — выбрать тип снаряда;
- `Esc` — вернуться к выбору арены после матча.

На телефоне используется горизонтальная ориентация. В портретном режиме игра
покажет подсказку повернуть устройство. Интерфейс учитывает вырезы экрана и
системные панели, а касание поля имени открывает экранную клавиатуру.

## Делегирование AI-моделям

Локальный помощник может отправить задачу OpenRouter, Groq или xAI. API-ключи
передаются только через переменные окружения и не должны попадать в репозиторий.

```bash
export OPENROUTER_API_KEY="ваш-ключ"
npm run delegate -- --provider openrouter --task "Проверь баланс урона"
```

Можно явно приложить выбранные файлы проекта:

```bash
npm run delegate -- --provider openrouter \
  --task "Найди риски в расчёте выстрела" \
  --context src/game/core/simulateShot.ts,tests/simulateShot.test.ts
```

После добавления `GROQ_API_KEY` и `XAI_API_KEY` одна задача отправляется всем
доступным провайдерам командой:

```bash
npm run delegate -- --all --task "Предложи три улучшения игрового баланса"
```

Для OpenRouter действует жёсткий локальный лимит кампании **$15**. Перед каждым
запросом помощник сверяет фактический расход ключа и текущую цену модели, затем
проверяет максимально возможную стоимость с учётом лимита ответа. Статус:

```bash
npm run delegate -- --budget-status
```

Дополнительно можно уменьшить предел конкретного запроса:

```bash
npm run delegate -- --provider openrouter --model moonshotai/kimi-k3 \
  --max-tokens 3500 --max-cost 0.50 --task "Проверь физику полёта"
```
